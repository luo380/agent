用户访谈有哪些常用方法？各自的适用场景是什么？
✨

根据团队知识库中的资料，用户访谈主要有 三种常用方法：

  • 半结构化访谈：有提纲但不严格按顺序，适合探索性研究，能在保证方向的同时挖掘意外洞察。
  • 情境访谈（Contextual Inquiry）：在用户真实工作场景中进行观察+提问，适合了解实际操作流程和痛点。
  • 影子跟访（Shadowing）：全程跟随用户不主动提问，适合了解长时间跨度的行为模式。

建议根据研究目标选择：探索动机→ 半结构化；了解流程→ 情境访谈；观察习惯→ 影子跟访。
